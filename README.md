## 💡 Introduction
During my time at Pinnacle Internship, I had the opportunity to work on several exciting projects that helped me develop my technical skills and gain practical experience in the field. This repository is a collection of those projects, each with its own unique challenges and solutions.

## 🛠 Projects

### 🔒 Password Analyzer
A tool designed to analyze the strength of passwords based on various criteria such as length, character diversity, and common patterns.
- **Technologies Used:** Python, Regular Expressions, Data Analysis Libraries (e.g., pandas).
- **Features:**
  - Checks password length.
  - Analyzes character types (uppercase, lowercase, digits, special characters).
  - Identifies common weak patterns.

### 🖼 Image Encryption Tool
An application that encrypts images to ensure their confidentiality and integrity using advanced encryption algorithms.
- **Technologies Used:** Python, OpenCV, Cryptography Libraries (e.g., PyCrypto).
- **Features:**
  - Encrypts and decrypts images.
  - Supports multiple image formats.
  - Ensures data privacy through strong encryption techniques.

### ⌨ Key Logger
A simple key logger that records keystrokes and stores them for analysis or monitoring purposes.
- **Technologies Used:** Python, Keyboard Hooking Libraries (e.g., pynput).
- **Features:**
  - Captures user keystrokes.
  - Logs keystrokes to a file.
  - Can be configured for specific applications or durations.

### 🔐 Text Encryption
A utility that encrypts text messages using various cryptographic methods to ensure secure communication.
- **Technologies Used:** Python, Cryptography Libraries (e.g., PyCrypto).
- **Features:**
  - Encrypts and decrypts text messages.
  - Supports different encryption algorithms (e.g., AES, RSA).
  - Provides a simple command-line interface for easy use.

## 🚀 Getting Started

### 📋 Prerequisites
Before you begin, ensure you have met the following requirements:
- Python installed (preferably version 3.x).

### 🔧 Installation
To set up the projects locally, follow these steps:

1. Clone the repository:
   ```sh
   git clone https://github.com/Nawin-Cyber-10/Pinnacle_InternTasks.git
   ```
2. Navigate to the project directory:
   ```sh
   cd Pinnacle_InternTasks
   ```

Each project has its own `requirements.txt` file listing the necessary dependencies. Install them by navigating to the respective project folder and running:
```sh
pip install -r requirements.txt ( If availabe )
```
